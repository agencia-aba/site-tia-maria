Publicar as alterações

Como o site é estático (sem banco de dados), a lista acima só existe nesta sessão do navegador. Para publicar de verdade:

  1. Salve o(s) arquivo(s) de imagem em assets/images/novidades/ no projeto.
  2. Copie o código abaixo e substitua o conteúdo de assets/js/novidades-data.js.
  3. Envie as imagens + o arquivo atualizado para a agência (ou faça o commit/push pelo GitHub Desktop, se preferir).
